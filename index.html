    Connectivity diagnostic

    Network Check

    Test whether the game platforms in this directory are reachable from your current browser and network — safely, from this page.

    How this works — and what it will never do

    This check performs ordinary browser requests (a no-cors fetch and a favicon image probe) against each listed gaming domain, with timeouts. Browser security means some results can be inconclusive — the tool never guesses that a site is blocked just because JavaScript can't read its response.

    • Reachable — your browser completed a request to the site.
    • Likely blocked / unreachable — requests failed or timed out consistently.
    • Unable to determine — the test was inconclusive (CORS, browser or extension interference).

    This is a passive diagnostic: no port scanning, no proxies, no tunnels, no DNS tricks, and no attempt to bypass any network filter or block you may be behind.
