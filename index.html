    Diagnostic

    Network check

    Test whether the platforms in this index are reachable from your current browser and network — from this page, passively.

    Method

    1. A no-cors GET fetch — an opaque response proves the request completed at network level.
    2. A favicon image probe as an independent fallback.
    3. One repeat fetch — a target is only reported red if it fails consistently.

    Results

    • Reachable — a request completed.
    • Likely blocked / unreachable — consistent failure while the local control passed.
    • Unable to determine — CORS, an extension, or an offline browser prevented a conclusion.

    Never

    • No proxies, tunnels or domain fronting
    • No port scanning or DNS manipulation
    • No attempts to bypass any filter or block

    A blocked-looking result is never stated as fact — browser security limits what a page can know.
